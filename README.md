# Senderkataster-Modder
Die Erweiterung hat die folgenden Funktionen:

- Die Information, welche Netzbetreiber an einem Standort sind, wird basierend auf den Angaben Protokoll(e) und Sendeleistung zu den Popups hinzugefügt. Die Informationen können stimmen, müssen sie aber nicht immer.
- Die Sendeleistung wird in den Popups genau angegeben und nicht mehr nur als Wertebereich.
- Ermöglicht es, weiter in die Karte hineinzuzoomen (Level 22 statt 15). In der Standardkonfiguration kann es vorkommen, dass Marker zu nahe beisammen sind, um jeden anklicken zu können.
- Deaktiviert den automatischen Zoom, wenn auf einen Marker geklickt wird.
- Versteckt das Informationsfeld unter dem Adresseingabefeld automatisch.
- Erhöht die Informationsdichte der Popups. Je nach Display können bis zu drei Station-Einträge auf einmal dargestellt werden.
- Verbessert die Darstellung des Adresseneingabefelds.

Der Changelog ist in der Datei [CHANGELOG.md](CHANGELOG.md) zu finden.

Die Erweiterung kann für Chromium-basierte Browser und Firefox über die jeweiligen Add-on-Stores installiert werden. Der folgende Link sollte automatisch zum passenden Store weiterleiten: https://skm.nerdtech.one/

Alternativ kann die Erweiterung auch direkt aus dem Repository installiert werden.

Weitere Informationen gibt es im entsprechenden Thema auf [lteforum.at](https://www.lteforum.at/mobilfunk/senderkataster-browsererweiterung.26248/).

## Installation der Entwicklungsversion
### Chromium
- Lade das Repo herunter und entpacke es.
- Besuche die Seite `chrome://extensions/`, aktiviere den Entwicklermodus oben rechts.
- Es erscheint oben links der Button „Entpackte Erweiterung laden“. Klicke auf ihn.
- Wähle den entpackten Erweiterungs-Ordner aus.
- Die Erweiterung steht dir bei künftigen Besuchen auf der Senderkataster-Webseite zur Verfügung.
### Firefox
- Lade das Repo herunter und entpacke es.
- Besuche die Seite `about:debugging#/runtime/this-firefox`.
- Klicke auf den Button „Temporäres Add-on" laden.
- Wähle das ZIP-Archiv im Erweiterungs-Ordner aus.
- Die Erweiterung steht dir zumindest temporär bei künftigen Besuchen auf der Senderkataster-Webseite zur Verfügung.
